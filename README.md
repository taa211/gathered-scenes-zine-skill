# 拾景纸刊 v10

## 社区 Fork

这是 `taa211` 维护的 v10 视觉工作流 Fork。

v10 的核心不是给照片套一个固定滤镜，而是先从每张照片中判断真正的视觉关系，再为这张照片选择专属的视觉机制，最后直接生成具有来源因果和视觉冲击力的纸刊作品。

## v10 做了什么

- 视觉决策卡：先明确主体、关系、画布方向、视觉转化和观看路径。
- 源照片因果链：每个主要形状、颜色和空间动作都必须能追溯到照片。
- 直接出图：决策卡完成后直接渲染，不再经过容易稀释意图的 `final_prompt` 中间层。
- 质量闸门：检查画面是否牵强、模板化、胆怯或失去源照片身份。

## 使用入口

将 `skills/scenes-gathered-zine-v10/` 安装到 Codex Skills 目录，然后调用：

```text

```

浏览器批量流程和离线测试位于 [`v10/`](v10/)；具体改动见 [`V10-MODIFICATIONS.md`](V10-MODIFICATIONS.md)。
